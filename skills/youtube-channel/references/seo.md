# YouTube 被搜到的写法（2026-09 查证）

## 官方口径（附出处）

| 项 | 官方说法 | 出处 |
|---|---|---|
| 搜索排序 | 看标题/描述/内容与搜索词的匹配，和同一搜索下哪些视频互动多；**不是按播放量** | support.google.com/youtube/answer/141805 |
| tags | "play a minimal role"，主要纠正易拼错的词 | answer/146402 |
| 描述 | 每个视频不同；挑 1–2 个主关键词在标题和描述都突出；上限 5000 字符 | answer/12948449 |
| 标题 | 上限 100 字符；不要标题党、全大写、「!!!」 | developers.google.com/youtube/v3/docs/videos |
| #话题标签 | 标题旁最多显示 3 个；超过 60 个全部忽略 | answer/6390658 |
| 章节 | 首个 00:00、至少 3 个、每段 ≥10 秒；手写覆盖自动章节 | answer/9884579 |
| 翻译元数据 | 翻译过的标题和描述能被对应语言的搜索找到 | answer/6289575 |
| 自动配音 | 中文视频可自动配英文，专有名词易错，先抽查 | answer/15569972 |
| 缩略图测试 | Test & compare 最多 3 组，按观看时长占比判胜，需高级功能 | answer/13861714 |

## 中文 AI 技术频道的标题模式（实例归纳）

- 李宏毅：`【课程名(年份)】第N講：一堂課搞懂XXX`
- 跟李沐学AI：`Transformer论文逐段精读【论文精读】`
- ZOMI酱：`XXX是怎么工作的？【AI芯片】NPU详解03`

共同点：【系列名】＋序号串成一套；英文术语原样；问句或「一堂课搞懂」式承诺。

## 简介模板

```
<主关键词 · 关键词 · 关键词>｜<系列名> 第N讲

<一句钩子：一个问题 + 一个反直觉的数>

📖 本课课件：<url>
📝 本课讲义：<url>
📚 全部课程目录：<url>

━━ 章节 ━━
0:00 ...
...

━━ <系列名> · 全部 N 个专题 ━━
① ... ← 本课
...

#话题1 #话题2 #话题3
```

英文本地化：一段英文摘要（注明 "Lecture in Mandarin Chinese with Chinese subtitles"）＋链接＋英文章节名（时间戳与中文一致）。

## 按收益排序的动作

1. 视频与播放列表都加英文标题/描述
2. 标题统一「【系列】第N讲 核心问题（英文术语）」
3. 简介首行关键词 + 完整 00:00 章节
4. 播放列表写清标题描述、按讲序排
5. 每讲剪 2–3 条 Shorts，Related video 指向完整版
6. 自动配音先抽查再决定
7. 上传人工校对过的中文字幕（和英文字幕）
8. 有流量后用 Test & compare 测封面
