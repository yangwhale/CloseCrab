# 提示表格式（s<N>-cues.json）

```json
{"html": "页面.html", "audio": "录音.mp3",
 "open": ["details:has(#anim-broadcast)"],
 "cues": [
  {"at": "好我们进入第一节", "target": "#s一 .stn", "kind": "none", "scroll": 40},
  {"at": "左上班长把一整份", "target": "#fig-coll-1n", "sub": [0.014,0.136,0.486,0.43], "kind": "box"},
  {"at": "大家看这几段小动画", "target": "details:has(#anim-broadcast)", "kind": "box",
   "play": ["#anim-broadcast", "#anim-scatter"]},
  {"at": "班长模式有个毛病", "target": "#fig-coll-1n", "sub": [0.014,0.768,0.986,0.905], "play": null}
 ]}
```

| 字段 | 含义 |
|---|---|
| `at` | 台词开头几个字（去标点匹配）；resolve 后变成 `t`（秒）。一条提示从它的 `t` 管到下一条的 `t` |
| `target` | CSS 选择器；优先用图的 `id`、标题的 `id` |
| `sub` | 子区域 `[x0,y0,x1,y1]`，按 target 宽高的比例；在 inspect 截的 PNG 上量 |
| `kind` | `box` 红框（默认）／`circle` 手绘圈／`under` 下划线／`none` 只滚动不标 |
| `color` | 默认 `#EA4335`；「先放着、后面讲」的块用灰 `#9AA0A6` |
| `spot` | `true` 时整屏压暗、只亮目标 |
| `play` | 这条起开始放的动画（选择器或列表），**一直放到后面出现 `"play": null` 或另一条 play**；其余视频停在第 0 帧 |
| `addclass` | `[[选择器, 类名], …]`：从这条起给元素加类，之前的帧摘掉（例：猜数题的答案区 `[".guess .rev","on"]`，讲到「答案是」才揭开）。位置按「加上之后」的版面量，所以只适合揭开的东西在它之前的提示目标**下方** |
| `scroll` | 强制把 target 顶部放在视口顶下方这么多像素（一般不用） |

## 滚动规则

- 整张图放得下（高 < 视口减吸顶目录）就让整图居中，框只画子区域 —— 同一张图上连续几条提示时画面不动，只有框在跳，最舒服。
- 放不下就居中子区域。
- 每次切换 0.9 秒缓动；框在切换后 0.5 秒开始描、0.6 秒描完。

## 写提示的经验

- 一句话一个动作：讲「左上/右上/左下/右下」就逐块框；讲总结句用 `none` 或框落点带。
- 讲到后面的图（开场钩子引用后文的数）可以直接跳过去框，下一句再回来。
- 动画：讲到它就 `play`，离开时写 `"play": null`，否则后面每帧都在 seek，渲染变慢。
