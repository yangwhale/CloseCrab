# B站 文案与引流（2026-09 调研，出处见链接）

## 投稿形态

- 1.5–2 小时的课：**单 P ＋ 分段章节**（网页端超 3 小时才提示拆分）；整套进合集（Lv2）或系列列表。
- 分区：投稿页若有「人工智能」就选它，否则 科技→计算机技术（tid 231）。

## 规则红线（社区公约 member.bilibili.com/studio/convention）

| 条 | 内容 | 我们怎么做 |
|---|---|---|
| 2-9 | 诱导到第三方平台注册/关注/交易，含第三方链接、二维码、账号 → 删除或限流 | 只挂自己的开源课程网站；不挂 YouTube、网盘、群二维码 |
| 2-1 | 网络代理软件（VPN）相关内容有风险 | 不提 YouTube（大陆需代理才能访问） |
| 2-8 | 标题党、封面与内容不符、无法证实的夸大 → 限流 | 标题说清讲什么；数字都能在课件里查到 |
| 3-2 | 重复投稿后投限流 | 不把同一讲既做分 P 又单独投 |
| 3-3 | 标签要与内容相关 | 10 个以内，全是内容关键词 |

## 标题 / 简介模板

```
标题：【免费开源课】专题N·<题目>：<一句钩子>          （≤80 字）
简介：
<钩子：一个问题 + 一个反直觉的数>

📖 课件与讲义（免费开源）：<课程站 URL>
📚 全部课程：<课程站 URL>

《<系列名>》共 N 个专题，每个一到两小时。章节时间点见置顶评论。
```

## 宣传文案三件套

1. **动态 / 朋友圈（短）**：一句定位 + 五讲清单（带 BV 号，动态里会渲染成卡片）+ 课程站。
2. **知乎 / 公众号（长）开头**：先抛 2–3 个硬问题（「为什么 128K 只留 8.58 GiB KV cache 而不是 488 GiB？」），再说课能帮你算清楚。
3. **一句话版**（签名 / 公告）：「免费开源课：以 XX 为线索，讲 XX，每一步都算给你看。」

## 冷启动

- 同日双发（B站 先），切 60–120 秒竖屏片段引到完整课，结尾口播＋字幕引导。
- 大模型有新发布时 24 小时内出对应切片（标题忠于内容）。
- 只参加内容真正对口的话题活动（如「AI开源先锋计划」）。
- 课程网站每页挂「B站 / YouTube」入口，做两边的中转站。
